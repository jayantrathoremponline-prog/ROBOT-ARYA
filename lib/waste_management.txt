Automatic Waste Segregator and Monitoring System is an automated dustbin which can be used by all level of society. This project is designed to sort the wet, dry and metallic wastes into each bin respectively. The main objective of this project is tp automatically segregate the waste based on its material and monitor daily waste disposal rates and apply proper maintenance of teh dustbin. Besides that, this project is to promote three R's (Reduce, Reuse and Recycle) concept among the citizens. This project uses three different types of sensors to separate three types of wastes. Moisture sensor is used to detect wet waste, inductive proximity sensor is used to detect metallic waste and Infrared Radiation or I.R. Sensor is used to detect dry waste. This project has been made with the help of Arduino-uno with ATMega328P micro-controller and the whole programming is done in Embedded-C language. It also has a L.C.D. Display which displays the type of waste being detected. It used Servo Motor to rotate the bins and brings a particular type of dustbin below the funnel. This servo motor is connected to the Arduino-uno and works according to the instruction given by Arduino.
